3D Digital Space

This project is a 3D room with blue walls, a window, a table, and a gray floor. I used different shapes, colors, lighting, and camera angles to create the room. The blue walls and dark shadows make the space look interesting and mysterious.

I created this artwork using 3D modeling. This project helped me learn how to build objects, use lighting, and create a digital space.
