Goldfish and Snacks Drawing Tool

Use the drawing tool below to make an underwater scene. Press a number key, then drag your mouse on the canvas.

  • 1 = orange fish
  • 2 = blue bubbles
  • 3 = pink snacks
  • 4 = blue water waves
  • 5 = yellow popcorn
  • 6 = green seaweed

Artist Statement

My drawing system is about the playful underwater world of goldfish and snacks. I changed the starter tools into six custom tools: orange fish with eyes, blue bubbles, pink snack squares, blue waves, yellow popcorn shapes, and green seaweed. I changed the colors, shapes, line weights, transparency, and mouse behavior so each drag creates a repeated mark. These changes encourage users to build a busy aquarium instead of making only ordinary lines. The fish and bubbles create movement, while the snacks add humor and color. The seaweed and waves make the canvas feel like an underwater space. My goal was to make the system simple, colorful, and fun to use while showing how code can express a personal idea.
